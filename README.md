# Histamine regulation in shaping spindle refractoriness: a computational modeling study

MATLAB code repository for the manuscript under revision.

## Repository Overview
This repository contains the core MATLAB code for the computational modeling study on histamine regulation of sleep spindle refractoriness.

## File Description
- Spindle_refractory_main.m: Main script for the simulation and analysis pipeline.
- wamsley_spindle_detection.m: Implementation of the spindle detection algorithm used in the study.
- N2_data_last.mat: Example preprocessed N2 sleep stage data (validation only).

## Running Environment
- MATLAB R2019b or later
- No additional toolboxes required.

## How to Run
1. Open MATLAB and go to the project folder.
2. Run in command window:
Spindle_refractory_main
